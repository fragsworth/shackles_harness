The tests under FROZEN_PATHS are frozen: never change them; a wrong test is UPSTREAM to SPEC-TO-TESTS. When SPEC-TO-TESTS was overridden, FROZEN_PATHS is empty and testPaths are in WRITE_PATHS: write the tests the spec's test plan names. verify ({{ step.verify }}) must pass within {{ step.verify_timeout }} s. When MERGE_IN_PROGRESS lists files, the worktree holds a merge with conflict markers: resolve exactly those files, keep both intents, run verify, and run no git command at all; the runner stages and commits the merge.

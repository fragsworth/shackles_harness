# drafts/

Working material for recreating shackles_harness from scratch. Nothing here
is implementation. Everything was produced from the spec.yaml files alone; the
previous implementation was not read.

- `draft-1/` … `draft-5/` — five independent from-scratch specs, one per
  drafter, each with its own `SPEC.md` entry point and a judgment-call log
  (`JUDGMENT-CALLS.md`; draft 3 continues in `JUDGMENT-CALLS-2.md`).
  The drafters did not see each other's work.
- `comparison/PROFILE-SCHEMA.md` — the 13 headings every draft profile follows.
- `comparison/profile-draft-N.md` — one profile per draft, written by an
  analyst who read only that draft, so the five are comparable heading by
  heading.
- `comparison/five-shackles-drafts.html` — the comparison page: where the
  drafts agree, a divergence matrix, the judgment-call schemes and the
  uncertainties every drafter hit, gaps against the brief, and the open
  questions the differences reduce to. Open it in a browser.

Reading order for a newcomer: this file, the comparison page, then any
draft's `SPEC.md`. The profiles are the fastest way into a single draft.

# 11 — Doctor & index (`doctor.py`, `index.py`)

**Purpose.** Two offline tools. `doctor` renders every prompt without a round and
reports everything that would refuse `start` or would surprise an agent. `index`
regenerates the routing file `INDEX.md` that AGENTS.md tells agents to grep.

**Owns.** The report shape S17; the list of checks; INDEX.md's format.

**Depends on.** 04, 05, 06, 07 (read-only git facts), 08 (`state.load` for the paused
round check). `doctor` does not import 10; it reuses `plumbing.placeholder_attempt`
and `steps.lint` directly so that a broken engine cannot break the diagnosis.

**Depended on by.** 03 (`doctor`, `index` commands), 10 (`advance.end` regenerates the
index; `round_start.preflight` reuses `doctor.checks_for_start`).

---

## `doctor.py`

- `run_doctor(ctx, *, offline: bool, strict: bool) -> Report` — S17. Checks by area:
  - `spec-files`: baseline present; drift per file (error when `strict`, else warning,
    with the diff text as detail); listed non-glob file missing (error).
  - `config`: `ConfigError` problems (errors); `defaulted` keys (warning each, with the
    default value); `unknown` keys (error) (JC-08, JC-09).
  - `roster`: problems (errors); `maxAgent`, `defaultAgent`, `gateAgent`,
    `systemTestAgent` not in the roster (error); any rung ranked above `maxAgent`
    (warning: "unreachable ceiling").
  - `steps`: `steps.lint` errors and warnings verbatim; prose files that nothing
    references and the table does not require (warning `unused prose`).
  - `prose`: for every step: producer/driver prompt, gate prompt (if gated), checkpoint
    text, plus the conflict prompt; render with placeholder namespaces (round `0000`,
    zero money, `project.remaining` computed from the real archives when `offline` is
    false else 0); each unresolved token is an error naming the prompt and token; each
    prompt's token estimate is reported and a warning is raised above
    `promptTokenWarning`; a `prose.X` cycle is an error.
  - `agent-defs`: stale list (error).
  - `owner-log`: absent or empty (error: "start will refuse"); corrupt lines (warning).
  - `git` (skipped when `offline`): version ≥ 2.38, remote exists, main exists, dirty
    living paths, worktrees holding non-ended rounds (info), paused round (info with
    the pause kind).
  - `hooks`: `.claude/settings.json` parses and names both hook commands (error if
    missing) — a missing prompt hook means no OWNER.log.
- `checks_for_start(ctx) -> list[str]` — the error strings of the areas `start`
  refuses on (everything above except `git` infos); used by `round_start.preflight`.
- `format_report(report: Report, json_out: bool) -> str`.
- `exit_code(report) -> int` — 1 when any error, else 0.

## `index.py`

- `generate(paths: Paths, cfg) -> str` — one line per file: `path — purpose`, where
  purpose is the first line of the file's leading comment or docstring (Python: the
  module docstring's first line; Markdown: the first heading; YAML/JSON: the first `#`
  comment line; prose `.txt`: the text before the first colon on line 1), or `(no
  header)`. Covers the harness root files, `src/`, `docs/`, `tests/`, `locked_prose/`,
  `.claude/`, and `archives/` at directory level only (`archives/rounds/ — one folder
  per round`). Sorted by path. A fixed 3-line preamble states that the file is
  generated by `run.py index` (JC-25).
- `regenerate(paths, cfg) -> bool` — writes `INDEX.md` if changed; returns whether it
  changed.
- `is_current(paths, cfg) -> bool` — used by the test and doctor (warning when stale).

## Invariants
- `doctor` never writes anything and never spawns or contacts an agent.
- `doctor --offline` needs no network and no remote.
- The `prose` area renders exactly the prompts `next` would produce, with the same
  `assemble_prompt`, so "renders in doctor" implies "renders at run time" for the same
  spec files.

# 20 — harness/ top level

Parent: `SPEC.md` §3. `harness/` is the harness root: every path in
`project.yaml` is relative to it. It holds the owner's spec files (never
written by the harness), three living folders (`src/`, `docs/`, `tests/`), the
record (`archives/`), and a handful of small root files described here.

```
harness/
  AGENTS.md, project.yaml, subAgents.yaml, locked_prose/   owner's; read-only to the harness
  INDEX.md            routing: one line per file or folder
  README.md           what it is, how to run it
  pyproject.toml      package manifest + pytest config
  local.yaml          generated, gitignored, no user input
  OWNER.log           gitignored; JSON lines appended by the prompt hook
  .worktrees/         gitignored; per-attempt git worktrees (35-src-git.md)
  .verify/            gitignored; scratch output of verification runs (36-src-checks.md)
  archives/           -> 25-archives.md
  src/                -> 30-src.md
  docs/               -> 50-docs.md
  tests/              -> 60-tests.md
```

## INDEX.md (hand-maintained, lint-checked)

"grep `INDEX.md` for routing" (AGENTS.md). One line per entry:
`<path>  <what it is, in one clause>`. It lists every top-level entry of
`harness/`, every module of `src/shackles/*/`, every file of `docs/`, every
test folder, and the round-folder layout. It is prose, so it is living and
charged; it stays terse. A lint test (`64-tests-lint-drift.md`) fails when a
file under `src/` or `docs/` or a folder under `tests/` is missing from it, or
when it names a path that does not exist. Depends on: nothing. Depended on by:
agents reading it; the lint test.

## README.md

For a human: what the harness is (two paragraphs), prerequisites (Python 3.12,
git with a remote, Claude Code), first-time setup (`pip install -e
harness[dev]`, `python harness/src/run.py setup`, restart the session), how a
round runs (pointer to `docs/PROCESS.md`), how to run the tests (`pytest
harness/tests -m "not live"`; live probes `-m live` with a key), and how to
accept a spec change (`run.py accept-spec`). Living, charged, kept short.

## pyproject.toml

- `[project]`: name `shackles-harness`, `requires-python >= 3.12`,
  dependencies `pyyaml`; optional `dev`: `pytest`.
- `[tool.pytest.ini_options]`: `testpaths = ["tests"]`, `pythonpath = ["src"]`,
  markers `live` (needs real agents; excluded by default in CI) and
  `mechanics` (runs whole rounds on temp repos); `addopts = "-q"`.
- No build backend beyond the standard one; `pip install -e harness` is
  only for the dependency list. `run.py` runs without installation.

## local.yaml (generated by `setup`/`doctor --fix`; gitignored; never user input)

Owned by `config/local.py` (`31-src-config.md`). Keys, all derived:

| key | meaning |
|---|---|
| `generatedAt` | UTC timestamp of the last write |
| `harnessRoot`, `repoRoot` | absolute paths as resolved on this machine |
| `python` | the interpreter used to run `setup` |
| `git.remote`, `git.mainBranch` | resolved remote name and main branch (defaults `origin`, `main`) |
| `rosterHash` | sha256 of `subAgents.yaml` at the time `.claude/agents/` was generated |
| `hooksHash` | sha256 of the hook block written into `.claude/settings.json` |
| `ownerLog.cursor` | number of `OWNER.log` entries already copied into some round's slice on this machine |
| `doctor.lastRun`, `doctor.lastResult` | when doctor ran and whether it was clean |

Rule: nothing here is ever edited by hand or read as a setting; deleting the
file is always safe (`setup` recreates it) `[JC-02]`.

## OWNER.log (gitignored; hook-written; runner-read)

JSON lines, one per owner prompt: `{"ts": "<UTC ISO>", "session": "<claude
session id>", "text": "<the prompt verbatim>"}`. Written only by the
`UserPromptSubmit` hook handler (`39-src-agents.md`). Read only by
`round/owner_log.py` (`34-src-round.md`) to build the round's slice and to
verify quotes. If the file does not exist, `start` refuses: without a log the
runner cannot verify a single owner word.
